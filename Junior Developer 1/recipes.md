# Junior Developer 1

## Assigned page: Recipes

Junior Developer 1 is responsible for building and maintaining the Recipes page for Cookie Corner.

### Wireframe

![Recipes page wireframe](<Junior Developer 1.png>)

### Page responsibilities

- Create the page content for `recipes.html`.
- Add several homemade cookie recipes with clear recipe names, short descriptions, ingredients, and directions.
- Use the Cookie Corner color palette and typography from the site plan:
  - Cream: `#F7EFDF`
  - Gold: `#E6B05D`
  - Rose: `#B26562`
  - Black: `#000000`
  - Georgia for headings and Arial for paragraph text.
- Add appropriate cookie images from the project image folder when they support the recipe content.
- Write meaningful alternative text for every image.
- Create the page-specific styles in `recipes.css` and keep the layout consistent with the main site.
- Include the shared navigation and footer so visitors can move between Home, Recipes, and Gallery.
- Make sure the page is readable on both desktop and mobile screens.
- Check that links, headings, images, and recipe information work correctly before handing off the page.

### Page goal

Visitors should be able to browse the available cookie recipes and easily understand what each recipe is, what ingredients it needs, and how to prepare it.
