# Junior Developer 2

## Assigned page: Gallery

Junior Developer 2 is responsible for building and maintaining the Gallery page for Cookie Corner.

### Wireframe

![Gallery page wireframe](<Junior Developer 2.png>)

### Page responsibilities

- Create the page content for `gallery.html`.
- Build a visually organized collection of cookie photographs that matches the site plan.
- Use images from the project image folder whenever possible and make sure each image has meaningful alternative text.
- Add short captions or descriptions when they help visitors understand the cookie image.
- Use the Cookie Corner color palette and typography from the site plan:
  - Cream: `#F7EFDF`
  - Gold: `#E6B05D`
  - Rose: `#B26562`
  - Black: `#000000`
  - Georgia for headings and Arial for paragraph text.
- Create the page-specific styles in `gallery.css` and keep the layout consistent with the main site.
- Include the shared navigation and footer so visitors can move between Home, Recipes, and Gallery.
- Make sure the gallery layout is readable and usable on both desktop and mobile screens.
- Use lazy loading for non-critical images when appropriate and check that images do not break the page layout.
- Check headings, links, image alternative text, and responsive behavior before handing off the page.

### Page goal

Visitors should be able to browse attractive cookie photographs, get inspired to bake, and easily return to the Home or Recipes page.
